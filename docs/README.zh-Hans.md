# YumoCut

YumoCut 是基于 Concat 修改的非官方衍生版，不是上游 Concat 的官方版本，也不由上游维护或背书。当前只承诺 Windows x86_64 版本。

- 项目与对应源码：https://github.com/Beau1314/YumoCut
- 下载：https://github.com/Beau1314/YumoCut/releases
- YumoCut 问题反馈：https://github.com/Beau1314/YumoCut/issues
- 上游 Concat：https://github.com/jub0t/Concat

YumoCut 保留上游的本地剪辑引擎，并加入启动更新提示、主程序与已登记用户插件的一键更新。内置效果随主程序更新，未登记的插件目录不会被改动。
