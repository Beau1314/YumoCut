# 效果系统多语言（v0.2.15）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.（本仓库交接约束禁止子代理，必须 inline 执行。）Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** effect.toml 携带翻译（i18n 子表），中文界面下调整面板与效果库不再显示英文，发布 v0.2.15。

**Architecture:** `concat-effects` 的 Manifest schema 加 `i18n: HashMap<语言码, 翻译>`；渲染层（studio.rs / keyframes.rs / 效果库）按 `i18n::current()` 取值、英文回退；126 个包的翻译由脚本批量写回。

**Tech Stack:** Rust (serde TOML)、Slint UI、Python 写回脚本、既有 .deps 发布链路。

## Global Constraints

- effect.toml 的 `format` 版本号不变（翻译字段可选，语义向后兼容）。
- 项目格式/`manifest.json` schema 不变（更新机制不动）。
- `document-features` 保持 0.2.12。
- 全程中文沟通；不用子代理；辅助文件放 `.deps/`。
- workspace 版本在 `src/Cargo.toml` `[workspace.package]`。

### Task 1: manifest.rs — i18n schema 与回退方法

**Files:**
- Modify: `src/crates/concat-effects/src/manifest.rs`（Meta 约 147 行起、Param 约 216 行起）
- Test: 同文件 `#[cfg(test)]` 区

**Interfaces（Produces）:**
```rust
pub struct EffectI18n { pub name: String, pub description: String, pub category: String } // 全 #[serde(default)]
pub struct ParamI18n { pub label: String, pub group: String, pub labels: Vec<String> }   // 全 #[serde(default)]
// Meta 与 Param 各加：
#[serde(default)]
pub i18n: std::collections::HashMap<String, EffectI18n>,   // Meta
#[serde(default)]
pub i18n: std::collections::HashMap<String, ParamI18n>,    // Param
// 便捷方法（回退英文）：
impl Meta   { pub fn name_in(&self, lang: &str) -> &str; pub fn description_in(&self, lang: &str) -> &str }
impl Param  { pub fn label_in(&self, lang: &str) -> &str; pub fn group_in(&self, lang: &str) -> &str }
```
